### `baltic/__init__.py`

Baltic media monitor: how Russian/Belarusian, neighbouring, other foreign and Baltic outlets cover LT/LV/EE.


### `baltic/__main__.py`

The command line, the only place that reads arguments and environment: `python -m baltic <command>`.

- `def produce` — Speed layer 1: publish GDELT files to Kafka from --since on, forever.
- `def monitor` — Speed layer 2: consume, close slots, alert, forever.
- `def seed` — Warm-start the monitor from the batch layer's history.
- `def mirror` — Backfill raw files; a failed download stops it with an error (re-run to resume).
- `def etl` — Batch layer: Spark over the raw files into the lake (or the live lake).
- `def measure` — One benchmark run, printed as JSON (bench runs this in a fresh process).
- `def bench` — The scaling study: E1, E2, E3, repeated and shuffled.
- `def match` — AI: match ru_by articles to Baltic ones via the embedding service and via shared names.
- `def sample` — Write the blind labelling sheets (pairs, detector hours) and their hidden keys.
- `def evaluate` — Score the filled-in sheets: precision per stratum (H3) and the detector's blind check.
- `def reconcile` — Check: Spark row counts = the independent collector's, day by day.
- `def stream_vs_batch` — Check: the monitor's slots = Spark over the same raw files, up to the horizon.
- `def report` — Every figure and summary.json.
- `def parser` — All commands and their arguments.
- `def main` — Parse arguments and run one command.

### `baltic/ai/__init__.py`

Cross-language story matching through the embedding service, and its blind evaluation.


### `baltic/ai/evaluate.py`

Evaluation by blind hand labels: the AI matcher (H3) and the spike detector.

- `def strata` — The four sampling strata as (russian_title, baltic_title) frames.
- `def blind` — Number the distinct items in a random order: (sheet with an empty label column, key).
- `def sample_pairs` — N pairs per stratum; a pair drawn by two strata is labelled once and counts for both.
- `def hours` — Every (slot, group) with its rolling-hour count and whether the detector alerted there.
- `def sample_slots` — The n strongest alerts and n busy (rolling hour >= BUSY) hours without one, with headlines.
- `def score` — Share of 'y' labels per value of `by`, with Wilson intervals; unlabelled items are left out.
- `def h3` — H3: at equal coverage, the embedding precision's lower bound beats the entity upper bound.

### `baltic/ai/match.py`

AI step: pair each Russian/Belarusian article about the Baltics with its closest Baltic article (+-48 h).

- `class Embedder` — Client of the embedding service: batches of headlines in, unit-length vectors out.
- `def google_token` — ID tokens from the VM's metadata server (or local service-account credentials).
- `def load` — Sources (ru_by about the Baltics) and candidates (Baltic outlets), each with minutes in `t`.
- `def by_embedding` — Index and cosine of each source's most similar candidate within +-window minutes (-1 = none).
- `def entities` — Each article's named people ('p:') and organisations ('o:').
- `def by_entities` — Index and number of shared names of each source's best candidate (>= 2 shared, else -1 / 0).
- `def match` — One row per source article with both matchers' best counterpart.

### `baltic/analysis/checks.py`

Correctness evidence, each with a pass/fail verdict.

### `baltic/analysis/hypotheses.py`

H1 and H2, each decided by a rule fixed before the 30-day data was seen.

- `def h1` — Attention: share of each group's articles that are about the Baltics.
- `def tone_differences` — ru_by mean tone minus each reference group's, on security or on non-security Baltic stories.
- `def h2` — Framing: H2a on non-security stories, H2b (equivalence) on security stories.

### `baltic/analysis/report.py`

- `def save` — Write a figure as PNG.
- `def attention_figure` — Figure 1: share of each foreign group's articles that are about the Baltics (H1 compares these).
- `def theme_figure` — Figure 2: themes over- and under-represented in ru_by coverage vs other foreign outlets.

### `baltic/article.py`

One GDELT GKG 2.1 row -> one Article: who published it, about which countries, on what topic, in what tone.

- `class Col` — Column positions in a GKG 2.1 row (GDELT GKG codebook).
- `class Article` — The compact record every layer passes around (Kafka message body, Spark row, AI input).
- `def group` — Classify a source domain into one of GROUPS by its top-level domain or known name.
- `def is_security` — True when any theme is military, conflict, border, terror, cyber or weapons related.
- `def is_relevant` — Kept by the batch layer: about a Baltic country, or published by a Baltic outlet.
- `def parse` — Turn one tab-separated GKG row into an Article; None for a malformed row.

### `baltic/batch/__init__.py`

The batch layer: backfill, Spark map/reduce into the lake, and the scaling study.


### `baltic/batch/baseline.py`

The baseline for the scaling study: the SAME map function as Spark, run by a multiprocessing.Pool.

- `def map_path` — Map one zip: summed row counts per key, and the ids of its relevant articles.
- `def run` — Map every file in `processes` worker processes, reduce in the parent; returns the measurements.

### `baltic/batch/bench.py`

The scaling study (requirement 2.3): every configuration, repeated, in a random order, resumable.

- `class Config` — One benchmark configuration.
- `def configs` — E1 + E2 + E3 as a set of distinct configurations (E1's 7-day run is also E2's 8-core run).
- `def schedule` — Every (configuration, repeat) pair in a reproducible random order.
- `def run_all` — Run every pending (configuration, repeat) as a subprocess; returns how many ran.

### `baltic/batch/etl.py`

The batch layer: PySpark map -> shuffle -> reduce over raw zips, then Spark SQL into silver and gold Parquet.

- `def session` — Spark in local mode: one JVM, `cores` worker threads (a single-node "cluster").
- `def transform` — Raw zips -> (silver articles, {gold table name: DataFrame}); nothing runs until an action.
- `def run` — Run the job; out=None measures without writing (benchmark). Returns the run's measurements.

### `baltic/batch/mapper.py`

The MAP step of the batch layer, shared by the Spark job (etl) and the plain-Python baseline.

- `def map_file` — Yield ("article", row) per relevant article, then ("count", (key, (rows, about))) per key.
- `def add_counts` — The REDUCE function: sum (rows, about) pairs.

### `baltic/batch/mirror.py`

Backfill: download GDELT's raw zips for a date range into the same layout the producer archives into.

- `def mirror` — Fetch every missing file of `days` days from day (YYYY-MM-DD); idempotent. Returns outcome counts.

### `baltic/detector.py`

Spike detector: is a group's rolling-hour count of security articles far above its usual for that hour?

- `class Alert` — One spike: the group, the slot it was detected in, the observed and the usual rolling-hour count.
- `class SpikeDetector` — Robust z-score of the rolling-hour count against the same hour on previous similar days.
- `def densify` — Rows (ts, group, count) -> one row per slot from first to last, one column per group, gaps = 0.
- `def backtest` — Run a detector over a densified table, slot by slot; returns every alert.

### `baltic/gdelt.py`

GDELT 2.0 as a data source: every 15 minutes one GKG zip per feed, named by its slot timestamp.

- `def to_time` — Slot timestamp -> datetime.
- `def to_ts` — Datetime -> slot timestamp.
- `def shift` — The slot `slots` steps (15 minutes each) after ts; negative steps go back.
- `def slots` — Every slot timestamp from first to last, inclusive, oldest first.
- `def day_slots` — Every slot of `days` days starting at day (YYYY-MM-DD).
- `def file_url` — Download URL of one GKG file.
- `def session` — HTTP session that retries connection errors and 5xx answers with backoff.
- `def latest` — Slot timestamp of the newest GKG file GDELT lists for a feed.
- `def download` — The zip's bytes; None only when GDELT answers 404 (it skipped that file). Other failures raise.
- `def read_rows` — The tab-separated rows of the CSV inside a GKG zip, streamed.

### `baltic/layout.py`

The file-system schema: every path the pipeline reads or writes is built here, and nowhere else.

- `def write_atomic` — Write via a temporary file and rename, so a reader never sees a half-written file.
- `class Lake` — A Spark output tree: silver articles plus gold aggregate tables.
- `class Layout` — All paths under one data root.

### `baltic/stats.py`

The two statistical tools every result uses, both thin wrappers over scipy.

- `class Estimate` — A point estimate with its 95 % confidence interval.
- `def ratio_difference` — sum(num_a)/sum(den_a) - sum(num_b)/sum(den_b), one array element per cluster (domain).
- `def wilson` — Share k/n with its 95 % Wilson interval.

### `baltic/stream/__init__.py`

The speed layer: GDELT -> Kafka -> slots and alerts, with a warm start from the batch layer.


### `baltic/stream/monitor.py`

Stream processing, the speed layer: Kafka -> per-slot counts -> spike alerts.

- `class Slot` — One 15-minute slot being assembled from messages.
- `class SlotAssembler` — The close rule, free of Kafka and files: messages in, closed slots out, oldest first.
- `class State` — What survives a restart: the detector's history and the last closed slot.
- `class Monitor` — Turns messages into closed slots, scores them and writes slots.jsonl / alerts.jsonl.
- `def consume` — The consume loop: poll, handle, commit when nothing is half-read.
- `def read_slots` — slots.jsonl as a frame, slot kept as its 14-character string, times as epoch seconds.

### `baltic/stream/producer.py`

Ingestion, the speed layer's first step: GDELT -> Kafka, then archive the raw zip.

- `class Sink` — Where a parsed file goes; KafkaSink in production, a list in the tests.
- `class KafkaSink` — Publishes one GDELT file as article messages plus a closing 'done' marker, keyed by slot.
- `class Ingestor` — Publishes, in time order, every slot from `since` to GDELT's newest that is not on disk yet.

### `baltic/stream/seed.py`

Warm start: the batch layer hands its history to the speed layer.

- `def history` — The lake's security series as a dense slot x group table over the whole backfilled window.
- `def seed` — Write the monitor's warm state; never overwrites a live state. Returns True when it wrote one.
